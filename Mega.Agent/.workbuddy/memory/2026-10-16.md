# 2026-10-16

## MegaAgent WPF 聊天应用（MAF + DeepSeek）从零搭建并全链路验收

- 经 grill-me 六个分支拷问定稿方案：MAF ChatClientAgent + OpenAI SDK 指向 DeepSeek 兼容端点；技能=系统提示词预设；本地 JSON 持久化；流式输出；明文 config.json 存 Key；服务层冒烟测试 + UI 人工验收。
- 工程结构：MegaAgent.slnx（.NET 10 默认 slnx）
  - `src/MegaAgent.Core`（net10.0）：Models + ConversationStore/SkillStore/SettingsStore/AgentService
  - `src/MegaAgent.App`（net10.0-windows WPF）：MVVM（CommunityToolkit.Mvvm 8.4.2）
  - `tests/MegaAgent.SmokeTest`：console 冒烟测试，真实调 DeepSeek
- **MAF 1.25.0 API 要点（与早期 GA 文档不同）**：
  - `AgentThread` 已更名 `AgentSession`；`agent.CreateSessionAsync()` / `SerializeSessionAsync(session)` / `DeserializeSessionAsync(JsonElement)`
  - Instructions 放 `ChatClientAgentOptions.ChatOptions = new ChatOptions { Instructions = ... }`
  - `RunStreamingAsync(string, session, cancellationToken:)` 产出 `AgentResponseUpdate`，取 `.Text`
  - 反射探查 API 的技巧：Xml doc grep（e:/.nuget/.../Microsoft.Agents.AI.xml）比猜快
- **机器 NuGet 配置坑**：机器级 NuGet.Config 含内网镜像 192.168.3.116:8081（401），解决方案下放 `nuget.config` `<clear/>` + nuget.org 解决。
- 验收结果（全部真实通过）：
  - 冒烟测试：流式回复、多轮上下文（会话序列化恢复）、技能注入三链路 ✅
  - UI 自动化（pywinauto UIA）：新建对话→发送→流式回复；第二轮模型准确复述上一条消息（MAF 会话恢复）；选"翻译助手"后 "hello world"→"你好世界，很高兴见到你"；重启后会话/技能完整恢复；设置弹窗"测试连接"返回 Pong；技能管理新建"中英润色"成功落盘
- WPF 常用 UIA 自动化坑：pywinauto `send_keys` 经中文 IME 会吞空格；WPF 复合 Content 按钮 UIA Name 为空需按坐标/枚举定位；ComboBox 用 `.select(index)` 而非点弹窗项；`app.window(title=...)` 对 owned dialog 不可靠，用 `Desktop.window(handle=hwnd)`。
- WPF 程序在 bash 里用 `&` 启动会被外壳回收，必须用 run_in_background 任务。
- 用户 DeepSeek Key 已预置于 `%APPDATA%\MegaAgent\config.json`（勿提交到任何仓库）。
