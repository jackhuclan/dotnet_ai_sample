# 2026-10-16

## MegaAgent WPF 聊天应用（MAF + DeepSeek）从零搭建并全链路验收

- 经 grill-me 六个分支拷问定稿方案：MAF ChatClientAgent + OpenAI SDK 指向 DeepSeek 兼容端点；技能=系统提示词预设；本地 JSON 持久化；流式输出；明文 config.json 存 Key；服务层冒烟测试 + UI 人工验收。
- 工程结构：MegaAgent.slnx（.NET 10 默认 slnx）
  - `src/MegaAgent.Core`（net10.0）：Models + ConversationStore/SkillStore/SettingsStore/AgentService
  - `src/MegaAgent.App`（net10.0-windows WPF）：MVVM（CommunityToolkit.Mvvm 8.4.2）
  - `tests/MegaAgent.SmokeTest`：console 冒烟测试，真实调 DeepSeek
- **MAF 1.25.0 API 要点（与早期 GA 文档不同）**：
  - `AgentThread` 已更名 `AgentSession`；`agent.CreateSessionAsync()` / `SerializeSessionAsync(session)` / `DeserializeSessionAsync(JsonElement)`
  - Instructions 放 `ChatClientAgentOptions.ChatOptions = new ChatOptions { Instructions = ... }`
  - `RunStreamingAsync(string, session, cancellationToken:)` 产出 `AgentResponseUpdate`，取 `.Text`
  - 反射探查 API 的技巧：Xml doc grep（e:/.nuget/.../Microsoft.Agents.AI.xml）比猜快
- **机器 NuGet 配置坑**：机器级 NuGet.Config 含内网镜像 192.168.3.116:8081（401），解决方案下放 `nuget.config` `<clear/>` + nuget.org 解决。
- 验收结果（全部真实通过）：
  - 冒烟测试：流式回复、多轮上下文（会话序列化恢复）、技能注入三链路 ✅
  - UI 自动化（pywinauto UIA）：新建对话→发送→流式回复；第二轮模型准确复述上一条消息（MAF 会话恢复）；选"翻译助手"后 "hello world"→"你好世界，很高兴见到你"；重启后会话/技能完整恢复；设置弹窗"测试连接"返回 Pong；技能管理新建"中英润色"成功落盘
- WPF 常用 UIA 自动化坑：pywinauto `send_keys` 经中文 IME 会吞空格；WPF 复合 Content 按钮 UIA Name 为空需按坐标/枚举定位；ComboBox 用 `.select(index)` 而非点弹窗项；`app.window(title=...)` 对 owned dialog 不可靠，用 `Desktop.window(handle=hwnd)`。
- WPF 程序在 bash 里用 `&` 启动会被外壳回收，必须用 run_in_background 任务。
- 用户 DeepSeek Key 已预置于 `%APPDATA%\MegaAgent\config.json`（勿提交到任何仓库）。

## 第二轮改造（同日）
- 用户要求的 6 项 UI 改造全部实现：侧栏可折叠（折叠后窗口收缩为 420x820 类手机尺寸，动画用 DoubleAnimation 驱动 Border.Width + Window.Width/Height）；模型下拉移入输入区；技能改为输入框 `/` 斜杠选择（带过滤、上下键、Enter 确认、Esc 关闭、已选技能 chip）；头像浮层菜单（Popup，水平居中于头像正上方，含模型设置/技能选择两项）；MdXaml 渲染助手消息 Markdown（流式按 200ms 节流刷新 Rendered）；技能编辑窗口不带预览（用户明确去掉）。
- **样式库换血**：ShadUI NuGet 包是 Avalonia 库（WPF 不可用，已向用户说明）；先手写了 shadcn 风格资源字典，后按用户要求整体切换为 HandyControl 3.6.0-rc3（支持到 net9.0，net10 可引用）。
- **HandyControl 接入要点**：App.xaml 合并 `pack://application:,,,/HandyControl;component/Themes/SkinDefault.xaml` + `Theme.xaml`；Theme.xaml 含隐式样式键（System.Windows.Controls.Button/ComboBox/ListBox/TextBox/ScrollViewer/Window/PasswordBox/ContextMenu 等原生控件全部被重写）；常用键：ButtonPrimary/ButtonDefault/ButtonIcon/ButtonDanger/ComboBoxExtend/EffectShadow1-5；画刷键：PrimaryBrush/RegionBrush/SecondaryRegionBrush/ThirdlyRegionBrush/BorderBrush/PrimaryTextBrush/SecondaryTextBrush/ThirdlyTextBrush/ReverseTextBrush/BackgroundBrush；hc:Card/hc:Empty(Description)/hc:Divider/hc:LoadingCircle/hc:Tag/hc:ComboBox/hc:TextBox(hc:InfoElement.Placeholder)/hc:PasswordBox/hc:MessageBox 可用。用 ResourceReader 读 g.resources + 运行时加载字典枚举 Keys 的工具化探查法可 100% 确认键名，避免运行时 XamlParseException。
- 已验证：折叠 630px(420DIP) 手机视图、展开恢复、头像菜单两入口、设置"测试连接"Pong、技能管理列表。注意：HandyControl ButtonDefault 有白底，做透明菜单项需覆写 Background/BorderBrush 并用 Trigger 恢复 hover。
- 用户在用时不要跑 UI 自动化（会抢占鼠标/前台），剩余人工验收项：斜杠技能选择、Markdown 渲染、发送链路（代码路径与 v1 相同，风险低）。
- MdXaml 用了用户指定的预览版 2.0.0-pre202603081301（API 与 1.27 兼容：MarkdownScrollViewer + MarkdownStyle.GithubLike）。

## 第三轮改造：抽屉式侧栏（用户追加 3 项需求）
- 窗口默认 9:16（450x800 DIP，DPI 150% 下实测 675x1200），ResizeMode=CanResizeWithGrip；OnRenderSizeChanged + Window_SizeChanged 用**外框尺寸**锁比例（用客户区会因标题栏/边框导致尺寸自激振荡收敛失败）。
- 侧栏改为抽屉：覆盖聊天区宽度 50%（Window_SizeChanged 里按 e.NewSize.Width*0.5 设 SidebarDrawer.Width），TranslateTransform 从 -width 滑入 + 半透明遮罩（点击遮罩关闭），默认 Visibility=Collapsed。
- 侧栏仅剩品牌+新建对话+历史对话列表；头像移至聊天区顶栏右上角，Popup Placement=Bottom、右边缘与头像对齐。
- **重要坑**：HandyControl 的 `ButtonIcon` 样式模板不渲染普通 Content（☰/«/✕/头像全部隐形）——改用自建 `GhostIconButton`（BasedOn ButtonDefault、透明底）解决。
- UIA 验证注意：Popup 弹窗用 `invoke()`（Invoke 模式）而非 click_input，不抢鼠标；截图只抓窗口 bbox（GetWindowRect + ImageGrab(bbox)）减少对用户桌面的干扰。
- 验证脚本：tests/MegaAgent.UiSmoke/verify_drawer.py；截图 docs/screenshots/drawer-hidden-default.png、drawer-open-50.png。

## 第四轮改造：固定窗口 + 细节修复
- 窗口固定尺寸：ResizeMode=NoResize（WS_THICKFRAME/WS_MAXIMIZEBOX 均已为 False），删除比例锁代码；抽屉宽度改在 Loaded 里按 RootLayout.ActualWidth*0.5 计算一次。
- 抽屉顶部去掉 MegaAgent 品牌区，改为「新建对话 + «(收起)」同行。
- 头像裁切根因：HC ButtonDefault 模板有固定 Height，内容(圆+padding)超高被裁——头像改为 Border(MouseLeftButtonDown) 直绘，不再套 Button。
- **重大 bug 修复**：hc:TextBox 丢失 `Text="{Binding DraftInput, UpdateSourceTrigger=PropertyChanged}"` 绑定（HC 重写时遗漏），导致 DraftInput 恒为空——"/"弹层与发送按钮全部失效；补上绑定后发送链路实测恢复（DeepSeek 流式回复正常）。
- UIA 教训：EnumWindows 找 "MegaAgent" 标题会撞上 WorkBuddy 聊天窗口（会话标题也含 MegaAgent），键盘自动化可能误伤用户当前窗口——用户在用电脑时禁止 send_keys 类操作，只用 invoke/set_edit_text 且先校验窗口类名/进程。

## 第六轮微调
- 模型列表改为 deepseek-flash / deepseek-v4-pro；SettingsStore.Load 与 MainViewModel 构造时对旧模型名做迁移回落（config.json 与会话 ModelId 不在列表中 → 默认第一个）。
